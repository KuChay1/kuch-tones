Guitar amp plug-in for metal and djent (AU, VST3 and a standalone app; macOS, Apple Silicon).

**Install:** download **KuchTones.pkg** from the [latest release](https://github.com/KuChay1/kuch-tones/releases/latest) and open it.
The first time, macOS blocks it: System Settings > Privacy & Security > **Open Anyway**.

**Amp captures:** not included (TONE3000 licence). After installing, open
`~/Library/Application Support/KuchDjent/Captures/READ ME.txt` for the free captures to download.

**Updates:** installed copies update themselves when the plug-in loads; quit and reopen the DAW to use the new version.
